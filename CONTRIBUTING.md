# Contributing to Sentinel-X

## Setup

bash
git clone https://github.com/SayAn1-dls/sentinel-x.git
cd sentinel-x/backend && pip install -r requirements.txt
cd ../frontend && npm install && npm run dev


## Commit Style
Use conventional commits: feat:, fix:, docs:, chore:, test:

## Branch Naming
- feat/description
- fix/description
- docs/description
