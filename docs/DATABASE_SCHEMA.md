# Database Schema

MongoDB database `sentinel_x` (`DB_NAME` in `render.yaml`). Field names below come from the code that writes each collection in `frontend/src/lib/server/` and `frontend/src/app/api/`. Field naming is mixed: auth collections (`users`, `user_sessions`) use snake_case, the rest use camelCase.

## Collections

### users
Written by `app/api/auth/session/route.ts`. The first user ever created gets `ADMIN`, everyone after gets `ANALYST`.
```json
{
  "user_id": "user_<12 hex chars>",
  "email": "string",
  "name": "string",
  "picture": "string",
  "role": "ADMIN | ANALYST",
  "created_at": "Date",
  "last_login": "Date"
}
```

### user_sessions
Written by `createSession` in `lib/server/auth.ts`. Sessions last 7 days.
```json
{
  "user_id": "string (users.user_id)",
  "session_token": "string",
  "expires_at": "Date",
  "created_at": "Date"
}
```

### transactions
Seeded (140 rows) by `ensureSeeded` in `lib/server/seed.ts` and generated by `lib/server/txgen.ts`.
```json
{
  "id": "string",
  "timestamp": "number (epoch ms)",
  "amount": "number",
  "currency": "USD | EUR | BTC | ETH | GBP",
  "sender": "string",
  "receiver": "string",
  "status": "CLEAN | PENDING | FLAGGED | BLOCKED",
  "threatLevel": "CLEAR | LOW | MEDIUM | HIGH | CRITICAL",
  "riskScore": "number (0-100)",
  "flags": ["string"],
  "metadata": { "region": "OFFSHORE | DOMESTIC", "channel": "WIRE | SWIFT | CHAIN | ACH", "encrypted": true }
}
```

### alerts
Seeded from the six highest-risk transactions. `PATCH /api/alerts/[id]` sets `resolved: true`.
```json
{
  "id": "string",
  "timestamp": "number (epoch ms)",
  "level": "threat level",
  "message": "string",
  "source": "string",
  "resolved": "boolean",
  "transactionId": "string (transactions.id)"
}
```

### audit_logs
Written by `recordAudit` in `lib/server/audit.ts`.
```json
{
  "id": "string",
  "timestamp": "number (epoch ms)",
  "action": "string",
  "actor": "string",
  "target": "string",
  "severity": "threat level",
  "details": "string",
  "ipAddress": "string (default 127.0.0.1)",
  "sessionId": "string (default SYSTEM)"
}
```

### gateways
Seeded with four static rows.
```json
{ "id": "string", "name": "string", "protocol": "string", "status": "ONLINE | DEGRADED", "latency": "number (ms)", "encryptionBits": "number", "lastChecked": "number (epoch ms)" }
```

### passkeys
Written when a WebAuthn credential is registered.
```json
{ "userId": "string (users.user_id)", "id": "string (credential id)", "publicKey": "Buffer", "counter": "number", "transports": ["string"], "deviceType": "string", "backedUp": "boolean", "label": "string" }
```

### webauthn_challenges
Short-lived (5 minutes). Registration challenges carry `userId`; login challenges carry `flowId`.
```json
{ "userId": "string (registration only)", "flowId": "string (authentication only)", "type": "registration | authentication", "challenge": "string", "expiresAt": "Date" }
```

## Indexes
Created by `ensureIndexes` in `lib/server/seed.ts`:
- `transactions.timestamp` (descending)
- `audit_logs.timestamp` (descending)
- `user_sessions.session_token`
- `passkeys.id`
- `webauthn_challenges.expiresAt` (TTL, `expireAfterSeconds: 0`)
- `users.email`
