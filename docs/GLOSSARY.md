# Glossary

## Terms Used in This Project

**Forensic Analysis** — The process of examining digital artifacts to identify threats or anomalies.

**Authenticator** — A device or app that generates time-based one-time passwords (TOTP) for 2FA.

**Passkey** — A FIDO2 passwordless credential bound to a device using biometrics or PIN.

**Threat Alert** — A flagged event in the system indicating potential unauthorized access or anomaly.

**Audit Log** — An immutable record of sensitive actions taken within the system.

**Session Exchange** — The backend handshake process that validates a Google OAuth token and issues a session.

**HUD** — Heads-Up Display; the dashboard UI showing live threat and forensic data.
